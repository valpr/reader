# Getting Started with Valpr Reader

Valpr Reader is a web-based e-book reader optimized for Japanese immersion, vertical-rl layouts, dictionary extensions, and cross-device reading continuity.

---

## Supported File Formats

Valpr Reader supports three primary Japanese book formats:

- **EPUB (`.epub`):** The standard format for light novels and Japanese literature. Valpr Reader parses Ruby annotations (`<ruby>`, `<rt>`), vertical typography, chapter manifests, and embedded images.
- **HTMLZ (`.htmlz`):** Zipped HTML e-book archives commonly exported from web novel downloaders (such as Syosetu/Narou downloaders).
- **TXT (`.txt`):** Plain text files with automatic Aozora Bunko (青空文庫) ruby and formatting syntax parsing.

---

## Adding Books to Your Library

1. **Drag and Drop:** Drag any `.epub`, `.htmlz`, or `.txt` file anywhere onto the reader library screen (`/manage`).
2. **File Picker:** Click the **+ Add Book** button in the library header to select files from your computer or phone.
3. **Cloud Sync:** Connect Google Drive or Microsoft OneDrive in **Settings > Data** to sync books seamlessly across your devices.

---

## Installing as a Progressive Web App (PWA)

Valpr Reader functions as a full Progressive Web App:

- **Desktop (Chrome / Edge / Brave):** Click the **Install App** icon in the address bar or select _Install Valpr Reader_ from the browser menu. Once installed, the reader runs in an isolated, borderless window with dedicated shortcuts.
- **Mobile (iOS Safari):** Tap the **Share** button at the bottom of Safari, then choose **Add to Home Screen**.
- **Mobile (Android Chrome):** Tap the three-dot menu and choose **Add to Home screen** or **Install App**.

Once installed, your library, books, and reading tracker are available completely **offline**.

## Basic Controls & Keyboard Shortcuts

| Action                     | Desktop Shortcut                        | Touch / Gesture                   |
| :------------------------- | :-------------------------------------- | :-------------------------------- |
| **Next Page**              | `Space`, `J`, `ArrowLeft` (vertical-rl) | Tap right/left edge or swipe left |
| **Previous Page**          | `K`, `ArrowRight` (vertical-rl)         | Tap opposite edge or swipe right  |
| **Toggle Menu**            | `M` or click reader header              | Tap screen center                 |
| **Toggle Reading Tracker** | `T`                                     | Tap tracker icon in header        |
| **Search in Book**         | `Ctrl+F` / `Cmd+F`                      | Open menu → Search icon           |
| **Bookmark Page**          | `B`                                     | Open menu → Bookmark icon         |
| **Fullscreen**             | `F11`                                   | Open menu → Fullscreen button     |
